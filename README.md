# Polymarket Trading Assistant - MVP Demo

快速交易辅助系统 Demo，仅用于学习和研究目的。

## 快速开始

```bash
cd polymarket-assistant
npm install
npm run dev
```

然后访问 http://localhost:3000

## 功能

- 📊 市场列表浏览与搜索
- 📈 价格走势图（模拟数据）
- ⚡ 快速模拟下单（YES/NO、数量、价格）
- ⚠️ 基础风险控制（单笔限制、重复下单提醒）
- 📋 订单历史记录

## 技术栈

- Next.js 14 + TypeScript + Tailwind
- Recharts 图表
- 纯前端 Mock 数据

## 注意事项

⚠️ 本 Demo 不涉及真实资金和真实交易，仅供学习参考。
